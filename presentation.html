📌 Problem Statement

Background

Bank cheque fraud remains a significant financial crime worldwide. One common technique involves adding or altering text on a legitimate cheque using a different pen with visually similar ink.


While such modifications may fool the human eye, computational analysis of ink properties can reveal subtle differences that indicate tampering.


Objective

  • Detect whether a cheque has been tampered with (different inks present)
  • Localize the regions where ink differences occur
  • Quantify the confidence of the fraud detection

Key Challenges

📉 Small Dataset

Only 112 cheque images available — 9 writers, 14 pens

🏷️ No Pixel-Level Labels

No segmentation masks or precise ink boundary annotations

🖊️ Visually Similar Inks

Different pens may produce nearly identical colors to the naked eye

✍️ Varying Handwriting

Different writers, writing speeds, and pen pressures

📚 Literature Review

Ink Differentiation in Documents

Dansena, Bag & Pal (2017) — "Differentiating Pen Inks in Hand-written Bank Cheques Using MLP"

  • 15 statistical features across color channels
  • K-means clustering for ink pixel identification
  • 94.6% accuracy for known pen samples

Siamese Networks

Bromley et al. (1994) & Koch et al. (2015)

  • Shared-weight twin architecture
  • Excel at few-shot & similarity learning
  • Learn a metric, not class boundaries

LAB Color Space

CIELAB separates luminance from chromaticity — ideal for ink analysis:

L ChannelInk density & darkness
A ChannelGreen ↔ Red tint
B ChannelBlue ↔ Yellow tint

Texture Analysis

  • GLCM (Haralick et al., 1973) — Spatial co-occurrence patterns
  • LBP (Ojala et al., 1996) — Local texture patterns around each pixel
  • Grad-CAM (Selvaraju et al., 2017) — Visual explanations from deep networks

🧠 Siamese Network (Primary Model)

Architecture (~200K params)

Input 3 × 64 × 64 RGB patch
Conv2d 3 → 32 channels, 3×3
BatchNorm + ReLU + MaxPool2d
Conv2d 32 → 64 channels, 3×3
BatchNorm + ReLU + MaxPool2d
Conv2d 64 → 128 channels, 3×3
BatchNorm + ReLU + MaxPool2d
AdaptiveAvgPool → (128,)
FC 128 → 64-dim embedding

Twin Branch Design

Similarity Score

Contrastive Loss

L = (1-Y) × 0.5 × D² + Y × 0.5 × max(0, margin - D)² Where: D = Euclidean distance between embeddings Y=1 → same ink (pull together) Y=0 → different ink (push apart) margin = 2.0

🔍 Fraud Detection Pipeline

1️⃣

Preprocessing

  • Resize to 256 × 512
  • Normalize to [0, 1]
  • Extract ink mask
  • Extract 64×64 patches
2️⃣

Region Analysis

  • Split into left/right regions
  • Cross-region pair comparison
  • Compute similarity scores
  • Build spatial heatmap
3️⃣

Verdict Decision

  • Adaptive outlier detection
  • Statistical spread analysis
  • Threshold-based verdict
  • Confidence scoring

Adaptive Outlier Detection (Siamese)

# Coefficient of variation — score spread cv = std_sim / (avg_sim + 1e-8) # Statistical outlier threshold adaptive_thresh = avg_sim - 2.0 * std_sim # Verdict requires BOTH conditions: if outlier_ratio > 0.20 and cv > 0.25: verdict = "FRAUD" else: verdict = "GENUINE"

Evaluation Metrics

  • Accuracy — Overall correct predictions
  • Precision — True positives / predicted positives
  • Recall — True positives / actual positives
  • F1-Score — Harmonic mean of precision & recall
  • ROC-AUC — Area under the ROC curve

Key Observations

  • Siamese excels due to metric learning — natural fit for small datasets
  • CNN tends to overfit faster but benefits from early stopping
  • Classical ML provides interpretable features but less representational power
  • LAB features contribute significantly across all models

Visual explanations for model decisions using gradient-based localization

# Grad-CAM Pipeline 1. Register forward/backward hooks on last conv layer 2. Capture activations during forward pass 3. Capture gradients during backward pass 4. Global average pool gradients → weights 5. Weighted sum of activation maps 6. ReLU → resize → normalize to [0,1] 7. Overlay colored heatmap on original image

Supports Both Model Types

CNN → Class activation Siamese → Embedding magnitude

For Siamese networks, Grad-CAM visualizes which spatial regions contribute most to the embedding vector, since there are no class outputs.
